---
title: Taller Banco Andino
description: Transacciones, concurrencia, índices y SQL avanzado sobre Oracle Autonomous Database.
---

Taller integrador de **Bases de Datos 2** (Universidad El Bosque) trabajado en parejas sobre **Oracle Autonomous Database** desde SQL Developer.

El caso es *Banco Andino*, una entidad financiera colombiana ficticia con 8 sucursales, 20 mil clientes, 30 mil cuentas, un catálogo de productos en tres niveles (línea de negocio, familia y producto), 200 mil transferencias y una cola de compensación interbancaria.

El taller se divide en cuatro partes:

1. Transacciones, concurrencia y bloqueos
2. Índices y optimización
3. SQL avanzado
4. Reto integrador
